# Enterprise Network Design using Cisco Packet Tracer

## 📌 Project Overview

A simulated enterprise network designed and configured using Cisco Packet Tracer.

The network connects multiple departments through a centralized core switch and provides DHCP-based IP addressing and network connectivity.

## 🏢 Departments

- Human Resources (HR)
- IT Department
- Finance Department

## 🛠️ Technologies & Concepts

- Cisco Packet Tracer
- LAN Networking
- VLANs
- DHCP
- IPv4 Addressing
- Default Gateway
- Core and Access Switches
- Network Connectivity Testing
- ICMP / Ping

## 🌐 Network Architecture

The network uses a hierarchical design consisting of:

- Enterprise Router
- Core Switch
- Department Access Switches
- Main Server
- Client PCs

## 🔧 Configuration

Configured features include:

- VLAN 10 – HR
- VLAN 20 – IT
- VLAN 30 – Finance
- DHCP pools for department networks
- Default gateways
- DNS configuration
- Access and trunk connectivity
- End-to-end connectivity testing

## 🧪 Testing

Connectivity was verified using ICMP ping tests between:

- PCs and the Main Server
- PCs and their default gateway
- Different network components
